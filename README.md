# Kitsune Client

[Download KitsuneLauncher.exe](https://github.com/HolyDanger/KitsuneClient-Releases/releases/download/r55-github/KitsuneLauncher.exe)

Download and run this single executable. The launcher downloads and verifies its runtime package automatically. The ZIP and encrypted `.enc` release assets are for automatic delivery; users do not need to unpack them manually.

Windows x64. Initial Minecraft/Java installation requires an internet connection. The online launch service must be available.

Launcher SHA-256:
```
2d9d54c752157154aa4f0c4bf1c55cab06dcfec77bc12ff5f1c5003d1fc8e8ec
```

This repository contains distribution binaries, public hashes, and the publishing workflow. Private source code and signing/content keys are not stored here.
